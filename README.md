# Capstone: Reservasi Lapangan Futsal

Komputasi Awan - Universitas Tanjungpura. Backend API (Node.js 20 + Express 4 + PostgreSQL 16)
di VPS dengan Docker Compose: 2 container app, Nginx load balancer, Prometheus + Grafana,
CI/CD GitHub Actions, dan hardening (SSH key, UFW, fail2ban, TLS, Helmet).

Endpoint: `GET /api/fields`, `POST /api/reservations`, `GET /health`.

Lihat `risk-register.md` untuk risk register.
